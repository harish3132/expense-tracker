
## Quick deployment (Vercel + Render + MongoDB Atlas)

1. Push this folder to a GitHub repository. Do not upload `server/.env`; it contains local-only settings and is excluded from this deployment ZIP.
2. Create a free MongoDB Atlas cluster and database user. In Atlas Network Access, allow `0.0.0.0/0` for this quick deployment. Copy the connection string and replace the password placeholder.
3. In Render, create a **Blueprint** from the GitHub repository. Render detects `render.yaml`; set `MONGO_URI` to the Atlas connection string when prompted. `JWT_SECRET` is generated by Render.
4. After the Render API is live, copy its URL (for example, `https://expense-tracker-api.onrender.com`).
5. In Vercel, import the same GitHub repository and set **Root Directory** to `client`. Add environment variable `VITE_API_URL` with the Render URL plus `/api` (for example, `https://expense-tracker-api.onrender.com/api`), then deploy.
6. Open the Vercel URL and register a test account.

Render's free web service may sleep when idle, so the first request after inactivity can take a little time. Never commit real database credentials or JWT secrets.
